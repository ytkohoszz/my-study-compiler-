# Obsidian community plugin

## Project overview

- Target: Obsidian Community Plugin (TypeScript → bundled JavaScript).
- Entry point: `src/main.ts` compiled to `main.js` and loaded by Obsidian.
- Required release artifacts: `main.js`, `manifest.json`, and optional `styles.css`.

## Environment & tooling

- Node.js: use current LTS (Node 18+ recommended).
- **Package manager: npm** (required for this sample - `package.json` defines npm scripts and dependencies).
- **Bundler: esbuild** (required for this sample - `esbuild.config.mjs` and build scripts depend on it). Alternative bundlers like Rollup or webpack are acceptable for other projects if they bundle all external dependencies into `main.js`.
- Types: `obsidian` type definitions.

**Note**: This sample project has specific technical dependencies on npm and esbuild. If you're creating a plugin from scratch, you can choose different tools, but you'll need to replace the build configuration accordingly.

### Install

```bash
npm install
```

### Dev (watch)

```bash
npm run dev
```

### Production build

```bash
npm run build
```

## Linting

- ESLint is preconfigured with `eslint-plugin-obsidianmd` for Obsidian-specific rules.
- Run `npm run lint` to lint the project.
- A GitHub Action automatically lints every commit on all branches.

## File & folder conventions

- **Organize code into multiple files**: Split functionality across separate modules rather than putting everything in `main.ts`.
- Source lives in `src/`. Keep `main.ts` small and focused on plugin lifecycle (loading, unloading, registering commands).
- **Example file structure**:
    ```
    src/
      main.ts           # Plugin entry point, lifecycle management
      settings.ts       # Settings interface and defaults
      commands/         # Command implementations
        command1.ts
        command2.ts
      ui/              # UI components, modals, views
        modal.ts
        view.ts
      utils/           # Utility functions, helpers
        helpers.ts
        constants.ts
      types.ts         # TypeScript interfaces and types
    ```
- **Do not commit build artifacts**: Never commit `node_modules/`, `main.js`, or other generated files to version control.
- Keep the plugin small. Avoid large dependencies. Prefer browser-compatible packages.
- Generated output should be placed at the plugin root or `dist/` depending on your build setup. Release artifacts must end up at the top level of the plugin folder in the vault (`main.js`, `manifest.json`, `styles.css`).

## Manifest rules (`manifest.json`)

- Must include (non-exhaustive):
    - `id` (plugin ID; for local dev it should match the folder name)
    - `name`
    - `version` (Semantic Versioning `x.y.z`)
    - `minAppVersion`
    - `description`
    - `isDesktopOnly` (boolean)
    - Optional: `author`, `authorUrl`, `fundingUrl` (string or map)
- Never change `id` after release. Treat it as stable API.
- Keep `minAppVersion` accurate when using newer APIs.
- Canonical requirements are coded here: https://github.com/obsidianmd/obsidian-releases/blob/master/.github/workflows/validate-plugin-entry.yml

## Testing

- Manual install for testing: copy `main.js`, `manifest.json`, `styles.css` (if any) to:
    ```
    <Vault>/.obsidian/plugins/<plugin-id>/
    ```
- Reload Obsidian and enable the plugin in **Settings → Community plugins**.

## Commands & settings

- Any user-facing commands should be added via `this.addCommand(...)`.
- If the plugin has configuration, provide a settings tab and sensible defaults.
- Persist settings using `this.loadData()` / `this.saveData()`.
- Use stable command IDs; avoid renaming once released.

## Versioning & releases

- Bump `version` in `manifest.json` (SemVer) and update `versions.json` to map plugin version → minimum app version.
- Create a GitHub release whose tag exactly matches `manifest.json`'s `version`. Do not use a leading `v`.
- Attach `manifest.json`, `main.js`, and `styles.css` (if present) to the release as individual assets.
- After the initial release, follow the process to add/update your plugin in the community catalog as required.

## Security, privacy, and compliance

Follow Obsidian's **Developer Policies** and **Plugin Guidelines**. In particular:

- Default to local/offline operation. Only make network requests when essential to the feature.
- No hidden telemetry. If you collect optional analytics or call third-party services, require explicit opt-in and document clearly in `README.md` and in settings.
- Never execute remote code, fetch and eval scripts, or auto-update plugin code outside of normal releases.
- Minimize scope: read/write only what's necessary inside the vault. Do not access files outside the vault.
- Clearly disclose any external services used, data sent, and risks.
- Respect user privacy. Do not collect vault contents, filenames, or personal information unless absolutely necessary and explicitly consented.
- Avoid deceptive patterns, ads, or spammy notifications.
- Register and clean up all DOM, app, and interval listeners using the provided `register*` helpers so the plugin unloads safely.

## UX & copy guidelines (for UI text, commands, settings)

- Prefer sentence case for headings, buttons, and titles.
- Use clear, action-oriented imperatives in step-by-step copy.
- Use **bold** to indicate literal UI labels. Prefer "select" for interactions.
- Use arrow notation for navigation: **Settings → Community plugins**.
- Keep in-app strings short, consistent, and free of jargon.

## Performance

- Keep startup light. Defer heavy work until needed.
- Avoid long-running tasks during `onload`; use lazy initialization.
- Batch disk access and avoid excessive vault scans.
- Debounce/throttle expensive operations in response to file system events.

## Coding conventions

- TypeScript with `"strict": true` preferred.
- **Keep `main.ts` minimal**: Focus only on plugin lifecycle (onload, onunload, addCommand calls). Delegate all feature logic to separate modules.
- **Split large files**: If any file exceeds ~200-300 lines, consider breaking it into smaller, focused modules.
- **Use clear module boundaries**: Each file should have a single, well-defined responsibility.
- Bundle everything into `main.js` (no unbundled runtime deps).
- Avoid Node/Electron APIs if you want mobile compatibility; set `isDesktopOnly` accordingly.
- Prefer `async/await` over promise chains; handle errors gracefully.

## Mobile

- Where feasible, test on iOS and Android.
- Don't assume desktop-only behavior unless `isDesktopOnly` is `true`.
- Avoid large in-memory structures; be mindful of memory and storage constraints.

## Agent do/don't

**Do**

- Add commands with stable IDs (don't rename once released).
- Provide defaults and validation in settings.
- Write idempotent code paths so reload/unload doesn't leak listeners or intervals.
- Use `this.register*` helpers for everything that needs cleanup.

**Don't**

- Introduce network calls without an obvious user-facing reason and documentation.
- Ship features that require cloud services without clear disclosure and explicit opt-in.
- Store or transmit vault contents unless essential and consented.

## Common tasks

### Organize code across multiple files

**main.ts** (minimal, lifecycle only):

```ts
import { Plugin } from 'obsidian';
import { MySettings, DEFAULT_SETTINGS } from './settings';
import { registerCommands } from './commands';

export default class MyPlugin extends Plugin {
	settings!: MySettings;

	async onload() {
		this.settings = Object.assign(
			{},
			DEFAULT_SETTINGS,
			(await this.loadData()) as Partial<MySettings>,
		);
		registerCommands(this);
	}
}
```

**settings.ts**:

```ts
export interface MySettings {
	enabled: boolean;
	apiKey: string;
}

export const DEFAULT_SETTINGS: MySettings = {
	enabled: true,
	apiKey: '',
};
```

**commands/index.ts**:

```ts
import { Plugin } from 'obsidian';
import { doSomething } from './my-command';

export function registerCommands(plugin: Plugin) {
	plugin.addCommand({
		id: 'do-something',
		name: 'Do something',
		callback: () => doSomething(plugin),
	});
}
```

### Add a command

```ts
this.addCommand({
	id: 'your-command-id',
	name: 'Do the thing',
	callback: () => this.doTheThing(),
});
```

### Persist settings

```ts
interface MySettings { enabled: boolean }
const DEFAULT_SETTINGS: MySettings = { enabled: true };

async onload() {
  this.settings = Object.assign({}, DEFAULT_SETTINGS, await this.loadData() as Partial<MySettings>);
  await this.saveData(this.settings);
}
```

### Register listeners safely

```ts
this.registerEvent(
	this.app.workspace.on('file-open', (f) => {
		/* ... */
	}),
);
this.registerDomEvent(activeWindow, 'resize', () => {
	/* ... */
});
this.registerInterval(
	window.setInterval(() => {
		/* ... */
	}, 1000),
);
```

## Troubleshooting

- Plugin doesn't load after build: ensure `main.js` and `manifest.json` are at the top level of the plugin folder under `<Vault>/.obsidian/plugins/<plugin-id>/`.
- Build issues: if `main.js` is missing, run `npm run build` or `npm run dev` to compile your TypeScript source code.
- Commands not appearing: verify `addCommand` runs after `onload` and IDs are unique.
- Settings not persisting: ensure `loadData`/`saveData` are awaited and you re-render the UI after changes.
- Mobile-only issues: confirm you're not using desktop-only APIs; check `isDesktopOnly` and adjust.

# Obsidian Sample Plugin

This is a sample plugin for Obsidian (https://obsidian.md).

This project uses TypeScript to provide type checking and documentation.
The repo depends on the latest plugin API (obsidian.d.ts) in TypeScript Definition format, which contains TSDoc comments describing what it does.

This sample plugin demonstrates some of the basic functionality the plugin API can do.

- Adds a ribbon icon, which shows a Notice when clicked.
- Adds a command "Open modal (simple)" which opens a Modal.
- Adds a plugin setting tab to the settings page.
- Registers a global click event and outputs a Notice on click.
- Registers a global interval which logs 'setInterval' to the console.

## First time developing plugins?

Quick starting guide for new plugin devs:

- Check if [someone already developed a plugin for what you want](https://obsidian.md/plugins)! There might be an existing plugin similar enough that you can partner up with.
- Make a copy of this repo as a template with the "Use this template" button (login to GitHub if you don't see it).
- Clone your repo to a local development folder. For convenience, you can place this folder in your `.obsidian/plugins/your-plugin-name` folder.
- Install NodeJS, then run `npm i` in the command line under your repo folder.
- Run `npm run dev` to compile your plugin from `src/main.ts` to `main.js`.
- Make changes to `src/main.ts` (or create new `.ts` files). Those changes should be automatically compiled into `main.js`.
- Reload Obsidian to load the new version of your plugin.
- Enable plugin in settings window.
- For updates to the Obsidian API run `npm update` in the command line under your repo folder.

## Releasing new releases

- Update your `manifest.json` with your new version number, such as `1.0.1`, and the minimum Obsidian version required for your latest release.
- Update your `versions.json` file with `"new-plugin-version": "minimum-obsidian-version"` so older versions of Obsidian can download an older version of your plugin that's compatible.
- Create new GitHub release using your new version number as the "Tag version". Use the exact version number, don't include a prefix `v`. See here for an example: https://github.com/obsidianmd/obsidian-sample-plugin/releases
- Upload the files `manifest.json`, `main.js`, `styles.css` as binary attachments. Note: The manifest.json file must be in two places, first the root path of your repository and also in the release.
- Publish the release.

> You can simplify the version bump process by running `npm version patch`, `npm version minor` or `npm version major` after updating `minAppVersion` manually in `manifest.json`.
> The command will bump version in `manifest.json` and `package.json`, and add the entry for the new version to `versions.json`

      e.preventDefault();
      this.searchInputEl?.focus();
      this.searchInputEl?.select();
      return;
    }

    const activeEl = document.activeElement;
    const inOtherInput =
      (activeEl instanceof HTMLInputElement && activeEl !== this.searchInputEl) ||
      activeEl instanceof HTMLSelectElement ||
      activeEl instanceof HTMLTextAreaElement;
    if (inOtherInput) return;

    const len = this.currentVisibleFlat.length;
    if (len === 0) return;

    if (e.key === "ArrowDown") {
      e.preventDefault();
      this.activeRowIndex = Math.min(len - 1, this.activeRowIndex + 1);
      this.highlightActiveRow();
    } else if (e.key === "ArrowUp") {
      e.preventDefault();
      this.activeRowIndex = Math.max(0, this.activeRowIndex - 1);
      this.highlightActiveRow();
    } else if (e.key === "Enter" && this.activeRowIndex >= 0) {
      const picked = this.currentVisibleFlat[this.activeRowIndex];
      if (picked) {
        e.preventDefault();
        this.openNote(picked.item.path);
      }
    } else if (
      (e.key === "ArrowRight" || e.key === "ArrowLeft") &&
      activeEl !== this.searchInputEl &&
      this.activeRowIndex >= 0
    ) {
      const picked = this.currentVisibleFlat[this.activeRowIndex];
      if (!picked || !picked.hasChildren) return;
      e.preventDefault();
      if (e.key === "ArrowRight") this.expanded.add(picked.item.path);
      else this.expanded.delete(picked.item.path);
      this.saveExpanded();
      this.renderTree();
    }
  }

        type: "button",
        title: root.isCompletedRoot
          ? "Вернуть корневой проект в список активных"
          : "Перевести корневой проект в завершённые",
      },
    });
    toggleRootStatusBtn.onclick = () => void this.toggleRootProjectStatus(root);

    const openBtn = row1.createEl("button", {
      cls: "my-sc-chip-btn",
      text: "📄 Открыть",
      attr: { type: "button", title: "Открыть заметку текущей ветки или проекта" },
    });
    openBtn.onclick = () => this.openNote(branchRoot.path);

    const directKidsCount = (this.scan.childrenOf.get(branchRoot.path) ?? []).length;
    const summaryRow = this.barEl.createDiv("my-sc-summary-row");
    const scopePrefix =
      branchRoot.path !== root.path ? `Ветка «${branchRoot.name}»: ` : "";
    summaryRow.createSpan({
      cls: "my-sc-summary-text",
      text:
        descendants.size > 0
          ? `${scopePrefix}материалов в дереве — ${descendants.size} (разделов 1-го уровня: ${directKidsCount})`
          : `${scopePrefix}материалов пока нет`,

      cls: "my-sc-chip-btn",
      text: "⤡ Свернуть всё",

    };

  private async toggleRootProjectStatus(root: StudyNoteItem) {
    const nextDone = !root.isCompletedRoot;
    try {
      await this.app.fileManager.processFrontMatter(
        root.file,
        (fm: Record<string, unknown>) => {
          fm[KEYS.status] = nextDone ? ROOT_STATUS_DONE : ROOT_STATUS_ACTIVE;
          if (nextDone && !fm[KEYS.finishedAt]) {
            fm[KEYS.finishedAt] = todayISO();
          }
        }
      );
      this.groupTab = nextDone ? "completed" : "active";
      this.plugin.settings.projectGroupTab = this.groupTab;
      this.plugin.requestSaveSettings();
      new Notice(
        nextDone
          ? `Проект «${root.name}» перенесён в завершённые`
          : `Проект «${root.name}» возвращён в активные`
      );
    } catch (err: unknown) {
      new Notice(
        "Не удалось изменить статус проекта: " +
          (err instanceof Error ? err.message : String(err))
      );
    }
  }

  private renderBreadcrumbs() {
    this.crumbsEl.empty();
    const root = this.getRootInCurrentGroup();
    if (!root) {
      this.crumbsEl.addClass("is-hidden");
      return;
    }
    const branchRoot = this.getActiveBranchRoot(root);
    if (branchRoot.path === root.path) {
      this.crumbsEl.addClass("is-hidden");
      return;
    }
    this.crumbsEl.removeClass("is-hidden");

    const chain = buildBreadcrumbChain(this.scan, root.path, branchRoot.path);
    this.crumbsEl.createSpan({ cls: "my-sc-crumbs-label", text: "Фокус ветки:" });

    chain.forEach((node, idx) => {
      if (idx > 0) {
        this.crumbsEl.createSpan({ cls: "my-sc-crumb-sep", text: "›" });
      }
      const isLast = idx === chain.length - 1;
      const btn = this.crumbsEl.createEl("button", {
        cls: "my-sc-crumb-btn" + (isLast ? " is-current" : ""),
        text: idx === 0 ? `🏠 ${node.name}` : node.name,
        attr: { type: "button" },
      });
      btn.onclick = () => this.setFocusBranch(root, node.path);
    });

    const resetBtn = this.crumbsEl.createEl("button", {
      cls: "my-sc-crumb-reset",
      text: "✕ Весь проект",
      attr: { type: "button", title: "Вернуться ко всему дереву проекта" },
    });
    resetBtn.onclick = () => this.setFocusBranch(root, root.path);
  }

  private async createNote(root: StudyNoteItem): Promise<boolean> {
    const cleanTitle = normalizeSpaces(this.form.title).replace(/[\\/:*?"<>|]/g, "");
    if (!cleanTitle) {
      new Notice("Введи название материала.");
      return false;
    }

    const normalizedType = normalizeSpaces(this.form.type) || "Материал";

    // Валидация произвольных свойств перед созданием файла
    const seenKeysLower = new Set<string>([
      KEYS.area.toLowerCase(),
      KEYS.type.toLowerCase(),
      KEYS.parent.toLowerCase(),
    ]);
    if (root.discipline) seenKeysLower.add(KEYS.discipline.toLowerCase());
    if (/^\d{4}-\d{2}-\d{2}$/.test(this.form.deadline)) {
      seenKeysLower.add(KEYS.deadline.toLowerCase());
    }

    const preparedProps: Array<{ key: string; serialized: string }> = [];

    for (const draft of this.form.customProps) {
      const k = normalizeSpaces(draft.key);
      const parsedVal = parseCustomPropertyValue(draft.value, draft.kind);
      if (!k && parsedVal === undefined) continue;
      if (!k) {
        new Notice("Укажи имя ключа для добавленного свойства или удали пустую строку.");
        return false;
      }
      if (isReservedYamlKey(k)) {
        new Notice(
          `Ключ «${k}» задаётся основными полями формы. Удали его из дополнительных свойств.`
        );
        return false;
      }
      const kLow = k.toLowerCase();
      if (seenKeysLower.has(kLow)) {
        new Notice(`Дублирующийся ключ свойства «${k}». Оставь только одно поле.`);
        return false;
      }
      if (parsedVal === undefined) continue; // Пустые значения не записываем совсем

      seenKeysLower.add(kLow);
      preparedProps.push({
        key: k,
        serialized: serializeYamlScalarOrList(parsedVal),
      });
    }

    const folder = normalizePath(this.plugin.settings.newNoteFolder || "Знания");
    const targetPath = normalizePath(`${folder}/${cleanTitle}.md`);
    if (this.app.vault.getAbstractFileByPath(targetPath)) {
      new Notice(`Заметка «${cleanTitle}» уже есть в папке ${folder}.`);
      return false;
    }
    const parent = this.scan.byPath.get(this.form.parentPath) ?? root;

    try {
      await ensureFolder(this.app, folder);
      const link = this.app.metadataCache.fileToLinktext(parent.file, targetPath);
      const lines = [
        "---",
        `${KEYS.area}: ${JSON.stringify(this.plugin.settings.studyAreaName)}`,
        `${KEYS.type}: ${JSON.stringify(normalizedType)}`,
        `${KEYS.parent}: ${JSON.stringify(`[[${link}]]`)}`,
      ];
      if (root.discipline) {
        lines.push(`${KEYS.discipline}: ${JSON.stringify(root.discipline)}`);
      }
      if (/^\d{4}-\d{2}-\d{2}$/.test(this.form.deadline)) {
        lines.push(`${KEYS.deadline}: ${JSON.stringify(this.form.deadline)}`);
      }
      for (const prop of preparedProps) {
        lines.push(`${prop.key}: ${prop.serialized}`);
      }
      lines.push("---", "", `# ${cleanTitle}`, "", "");
      await this.app.vault.create(targetPath, lines.join("\n"));

      this.plugin.settings.lastUsedMaterialType = normalizedType;
      this.expanded.add(parent.path);
      this.saveExpanded();
      new Notice(`Создано: «${cleanTitle}» (${normalizedType})`);
      return true;
    } catch (err: unknown) {
      new Notice("Ошибка создания: " + (err instanceof Error ? err.message : String(err)));
      return false;
    }
  }

  private renderDeadline(parent: HTMLElement, item: StudyNoteItem) {
    if (!item.deadline) return;
    const tone = getDeadlineTone(item);
    const cls =
      tone === "overdue"
        ? " is-overdue"
        : tone === "soon"
          ? " is-soon"
          : " is-far";
    parent.createSpan({
      cls: "my-sc-deadline" + cls,
      text: `⏳ ${formatDeadlineBadge(item)}`,
      attr: {
        title: formatFullDateTooltip(item.deadline),
      },
    });
  }

  private renderHighlightedTitle(container: HTMLElement, text: string, query: string) {
    const cleanQ = query
      .trim()
      .split(/\s+/)
      .filter((t) => !t.startsWith("#"))[0];
    if (!cleanQ) {
      container.setText(text);
      return;
    }
    const lowerText = text.toLowerCase();
    const lowerQ = cleanQ.toLowerCase();
    const idx = lowerText.indexOf(lowerQ);
    if (idx === -1) {
      container.setText(text);
      return;
    }
    if (idx > 0) container.appendText(text.slice(0, idx));
    container.createEl("mark", {
      cls: "my-sc-hl",
      text: text.slice(idx, idx + cleanQ.length),
    });
    if (idx + cleanQ.length < text.length) {
      container.appendText(text.slice(idx + cleanQ.length));
    }
  }

  private openNote(path: string) {
    this.noRestore();
    this.close();
    void this.app.workspace.openLinkText(path, "", false);
  }

  private renderTree() {
    const scrollTop = this.treeEl.scrollTop;
    this.treeEl.empty();
    this.rowElementByPath.clear();
    const root = this.getRootInCurrentGroup();
    if (!root) return;

    const branchRoot = this.getActiveBranchRoot(root);
    const nestedNodes = buildNestedFilteredTree(
      branchRoot,
      this.scan,
      this.expanded,
      {
        query: this.searchQuery,
        mode: this.filterMode,
        typeFilter: this.typeFilter,
      }
    );
    this.currentVisibleFlat = flattenVisibleTree(nestedNodes);

    if (nestedNodes.length === 0) {
      const hasFilters =
        this.searchQuery.trim().length > 0 ||
        this.filterMode !== "all" ||
        this.typeFilter.length > 0;
      this.treeEl.createDiv({
        cls: "my-sc-empty",
        text: hasFilters
          ? "По текущему запросу или фильтру ничего не найдено."
          : "В этой ветке пока нет материалов. Нажми «＋ Добавить материал».",
      });
      return;
    }

    const listEl = this.treeEl.createDiv("my-sc-tree-list");
    for (const node of nestedNodes) {
      this.renderNodeGroup(listEl, node, root);
    }

    if (this.activeRowIndex >= 0) {
      this.highlightActiveRow();
    }
    this.treeEl.scrollTop = scrollTop;
  }

  private renderNodeGroup(
    parentContainer: HTMLElement,
    node: TreeNode,
    projectRoot: StudyNoteItem
  ) {
    const item = node.item;
    const depthSlot = node.depth % 5;

    const groupEl = parentContainer.createDiv({
      cls:
        "my-sc-node-group" +
        ` is-depth-${depthSlot}` +
        (node.hasChildren ? " is-branch" : " is-leaf") +
        (node.isExpanded ? " is-expanded" : " is-collapsed"),
    });

    const row = groupEl.createDiv({
      cls:
        "my-sc-tree-row" +
        (node.hasChildren ? " is-parent-row" : "") +
        (node.isExpanded ? " is-open-parent" : "") +
        (node.isDirectMatch ? " is-match" : ""),
    });
    this.rowElementByPath.set(item.path, row);

    const left = row.createDiv("my-sc-tree-left");

    if (node.hasChildren) {
      const toggleBtn = left.createEl("button", {
        cls: "my-sc-toggle-btn" + (node.isExpanded ? " is-open" : ""),
        text: "▸",
        attr: {
          type: "button",
          title: node.isExpanded ? "Свернуть ветку" : "Развернуть ветку",
          "aria-label": node.isExpanded ? "Свернуть ветку" : "Развернуть ветку",
          "aria-expanded": String(node.isExpanded),

export function flattenFrontmatterValue(val: unknown): string[] {
  if (val === null || val === undefined) return [];
  if (Array.isArray(val)) {

    return res;

  if (typeof val === "object" && (val as { path?: unknown }).path) {

export function resolveParentPaths(
  app: App,
  file: TFile,
  rawParentProp: unknown
): string[] {
  const resolved: string[] = [];
  for (const raw of flattenFrontmatterValue(rawParentProp)) {
    const clean = stripOuterWikiBrackets(raw).split("|")[0]?.split("#")[0]?.trim();
    if (!clean) continue;

    const direct = app.vault.getAbstractFileByPath(clean);
    if (direct instanceof TFile) {
      if (!resolved.includes(direct.path)) resolved.push(direct.path);
      continue;
    }
    const withMd = app.vault.getAbstractFileByPath(
      clean.endsWith(".md") ? clean : `${clean}.md`
    );
    if (withMd instanceof TFile) {
      if (!resolved.includes(withMd.path)) resolved.push(withMd.path);
      continue;
    }
    const dest = app.metadataCache.getFirstLinkpathDest(clean, file.path);
    if (dest instanceof TFile && !resolved.includes(dest.path)) {
      resolved.push(dest.path);
    }
  }
  return resolved;
}

export function todayISO(): string {
  const d = new Date();
  const p = (n: number) => String(n).padStart(2, "0");
  return `${d.getFullYear()}-${p(d.getMonth() + 1)}-${p(d.getDate())}`;
}

export function daysUntilISO(iso: string): number {
  const parts = iso.split("-").map(Number);
  const y = parts[0];
  const m = parts[1];
  const d = parts[2];
  if (!y || !m || !d) return 999;

  const now = new Date();
  const todayLocalMidnight = new Date(
    now.getFullYear(),
    now.getMonth(),
    now.getDate()
  );
  const targetLocalMidnight = new Date(y, m - 1, d);
  return Math.round(
    (targetLocalMidnight.getTime() - todayLocalMidnight.getTime()) / 86_400_000
  );
}

export function pluralizeDays(n: number): string {
  const abs = Math.abs(Math.trunc(n));
  const mod100 = abs % 100;
  const mod10 = abs % 10;
  if (mod100 >= 11 && mod100 <= 19) return `${abs} дней`;
  if (mod10 === 1) return `${abs} день`;
  if (mod10 >= 2 && mod10 <= 4) return `${abs} дня`;
  return `${abs} дней`;
}

export function getDeadlineTone(item: StudyNoteItem): DeadlineTone {
  if (!item.deadline || item.isCompletedRoot) return "none";
  const diff = daysUntilISO(item.deadline);
  if (diff < 0) return "overdue";
  if (diff <= 7) return "soon";
  return "far";
}

export function formatDeadlineBadge(item: StudyNoteItem): string {
  if (!item.deadline) return "";
  if (item.isCompletedRoot) {
    return `${item.deadline.slice(8, 10)}.${item.deadline.slice(5, 7)}.${item.deadline.slice(0, 4)}`;
  }
  const diff = daysUntilISO(item.deadline);
  if (diff === 0) return "сегодня";
  if (diff === 1) return "завтра";
  if (diff > 1) return `осталось ${pluralizeDays(diff)}`;
  if (diff === -1) return "просрочено на 1 день";
  return `просрочено на ${pluralizeDays(Math.abs(diff))}`;
}

  return `Дедлайн: ${parts[2]}.${parts[1]}.${parts[0]}`;

function isTemplateOrExcludedFile(
  file: TFile,
  fm: Record<string, unknown>,
  tagsLower: string[],
  settings: StudyCompilerSettings
): boolean {
  const excludedFolders = settings.excludedFolders
    .map((f) => f.trim().replace(/^\/+|\/+$/g, "").toLowerCase())
    .filter((f) => f.length > 0);

  const pathLower = file.path.toLowerCase();
  const folderSegments = pathLower.split("/").slice(0, -1);
  for (const exFolder of excludedFolders) {
    if (
      pathLower.startsWith(`${exFolder}/`) ||
      folderSegments.includes(exFolder)
    ) {
      return true;
    }
  }

  const prefixes = settings.excludedTitlePrefixes
    .map((p) => p.trim().toLowerCase())
    .filter((p) => p.length > 0);
  const baseLower = file.basename.toLowerCase();
  if (prefixes.some((pref) => baseLower.startsWith(pref))) {
    return true;
  }

  const excludedTags = settings.excludedTags
    .map((t) => t.trim().replace(/^#/, "").toLowerCase())
    .filter((t) => t.length > 0);
  if (tagsLower.some((t) => excludedTags.includes(t))) {
    return true;
  }

  const noteTypeLower = readString(fm[KEYS.type]).toLowerCase();
  if (noteTypeLower === "шаблон" || noteTypeLower === "template") {
    return true;
  }
  if (
    fm[KEYS.templateFlag] === true ||
    String(fm[KEYS.templateFlag]).toLowerCase() === "true"
  ) {
    return true;
  }

  return false;
}

  KEYS.area,

  "position",

]);

export function scanStudyVault(
  app: App,
  settings: StudyCompilerSettings
): ScanResult {
  const byPath = new Map<string, StudyNoteItem>();
  const typeCounter = new Map<string, { display: string; count: number }>();
  const propKeyFreq = new Map<string, number>();
  const valuesSetByKey = new Map<string, Set<string>>();

  for (const file of app.vault.getMarkdownFiles()) {
    const cache = app.metadataCache.getFileCache(file);
    const fm = cache?.frontmatter;
    if (!fm) continue;

    if (!flattenFrontmatterValue(fm[KEYS.area]).includes(settings.studyAreaName)) {
      continue;
    }

    const isCardDeck =
      Boolean(fm["колода_карточек"]) ||
      readString(fm["подтип"]).toLowerCase() === "карточки";
    if (isCardDeck) continue;

    const rawTags = cache ? getAllTags(cache) ?? [] : [];
    const tags = rawTags.map((t) => t.replace(/^#/, "").toLowerCase());

    if (isTemplateOrExcludedFile(file, fm, tags, settings)) {
      continue;
    }

    const noteType = normalizeSpaces(readString(fm[KEYS.type]));
    if (noteType) {
      const lowerT = noteType.toLowerCase();
      const prev = typeCounter.get(lowerT);
      if (prev) prev.count++;
      else typeCounter.set(lowerT, { display: noteType, count: 1 });
    }

    for (const [k, rawVal] of Object.entries(fm)) {
      if (SYSTEM_FM_IGNORE.has(k)) continue;
      propKeyFreq.set(k, (propKeyFreq.get(k) ?? 0) + 1);
      const flatVals = flattenFrontmatterValue(rawVal);
      if (flatVals.length > 0) {
        let vSet = valuesSetByKey.get(k);
        if (!vSet) {
          vSet = new Set<string>();
          valuesSetByKey.set(k, vSet);
        }
        if (vSet.size < 40) {
          for (const fv of flatVals) {
            if (fv.length <= 80) vSet.add(fv);
          }
        }
      }
    }

    const status = normalizeSpaces(readString(fm[KEYS.status]));
    const rawDeadline = (
      readString(fm[KEYS.deadline]) || readString(fm[KEYS.deadlineAlt])
    ).slice(0, 10);
    const rawFinished = readString(fm[KEYS.finishedAt]).slice(0, 10);

    byPath.set(file.path, {
      file,
      path: file.path,
      name: file.basename,
      noteType,
      status,
      isCompletedRoot: isRootStatusCompleted(status),
      finishedAt: /^\d{4}-\d{2}-\d{2}$/.test(rawFinished) ? rawFinished : null,
      discipline: readString(fm[KEYS.discipline]),
      deadline: /^\d{4}-\d{2}-\d{2}$/.test(rawDeadline) ? rawDeadline : null,
      icon: readString(fm[KEYS.icon]),
      tags,
      parentPaths: resolveParentPaths(app, file, fm[KEYS.parent]),
    });
  }

  const childrenOf = new Map<string, string[]>();

  for (const item of byPath.values()) {
    const parents = item.parentPaths.filter((p) => p !== item.path && byPath.has(p));
    item.parentPaths = parents;
    for (const p of parents) {
      const list = childrenOf.get(p) ?? [];
      if (!list.includes(item.path)) list.push(item.path);
      childrenOf.set(p, list);
    }
  }

  const roots: StudyNoteItem[] = [];
  const orphans: StudyNoteItem[] = [];
  const legacyMaterialsLower = new Set(
    LEGACY_MATERIAL_TYPES.map((t) => t.toLowerCase())
  );

  for (const item of byPath.values()) {
    if (item.parentPaths.length > 0) continue;

    const hasChildren = (childrenOf.get(item.path)?.length ?? 0) > 0;
    const hasRootMarkers = Boolean(item.status || item.deadline);
    const isLegacyLeafMaterial =
      !hasChildren &&
      !hasRootMarkers &&
      legacyMaterialsLower.has(item.noteType.toLowerCase());

    if (isLegacyLeafMaterial) {
      orphans.push(item);
    } else {
      roots.push(item);
    }
  }

  const activeRoots = roots
    .filter((r) => !r.isCompletedRoot)
    .sort(sortActiveRoots);
  const completedRoots = roots
    .filter((r) => r.isCompletedRoot)
    .sort(sortCompletedRoots);
  roots.sort(byName);
  orphans.sort(byName);

  const typeCounts: TypeSuggestion[] = [...typeCounter.values()]
    .map((x) => ({ name: x.display, count: x.count }))
    .sort((a, b) => b.count - a.count || a.name.localeCompare(b.name, "ru"));

  const propertyKeys = [...propKeyFreq.entries()]
    .sort((a, b) => b[1] - a[1] || a[0].localeCompare(b[0], "ru"))
    .map(([k]) => k);

  const valuesByKey = new Map<string, string[]>();
  for (const [k, set] of valuesSetByKey.entries()) {
    valuesByKey.set(
      k,
      [...set].sort((a, b) => a.localeCompare(b, "ru", { numeric: true }))
    );
  }

  return {
    roots,
    activeRoots,
    completedRoots,
    orphans,
    byPath,
    childrenOf,
    schema: { typeCounts, propertyKeys, valuesByKey },
  };
}

export function findCaseInsensitiveTypeMatch(
  input: string,
  suggestions: TypeSuggestion[]
): string | null {
  const clean = normalizeSpaces(input);
  if (!clean) return null;
  const lower = clean.toLowerCase();
  for (const s of suggestions) {
    if (s.name.toLowerCase() === lower && s.name !== clean) {
      return s.name;
    }
  }
  return null;
}

/**
 * Преобразует строковый ввод произвольного свойства в корректный тип для YAML:
 * - пустая строка -> undefined (не записывать)
 * - kind === "list" -> массив строк по запятой
 * - YYYY-MM-DD -> строка (будет записана в кавычках в YAML)
 * - true / false -> boolean
 * - число -> number без кавычек
 */
export function parseCustomPropertyValue(
  rawValue: string,
  kind: CustomPropValueKind
): unknown {
  const trimmed = rawValue.trim();
  if (!trimmed) return undefined;

  if (kind === "list") {
    const items = trimmed
      .split(",")
      .map((x) => normalizeSpaces(x))
      .filter((x) => x.length > 0);
    return items.length > 0 ? items : undefined;
  }

  if (/^\d{4}-\d{2}-\d{2}$/.test(trimmed)) {
    return trimmed;
  }
  if (trimmed === "true") return true;
  if (trimmed === "false") return false;

  if (/^-?\d+(?:\.\d+)?$/.test(trimmed)) {
    const num = Number(trimmed);
    if (Number.isFinite(num)) return num;
  }

  return trimmed;
}

export function serializeYamlScalarOrList(val: unknown): string {
  if (Array.isArray(val)) {
    return `[${val.map((x) => JSON.stringify(String(x))).join(", ")}]`;
  }
  if (typeof val === "number" || typeof val === "boolean") {
    return String(val);
  }
  return JSON.stringify(String(val ?? ""));
}

export function isReservedYamlKey(key: string): boolean {
  const low = normalizeSpaces(key).toLowerCase();
  return RESERVED_YAML_KEYS.some((k) => k.toLowerCase() === low);
}

export function findRootPath(scan: ScanResult, path: string): string {
  const seen = new Set<string>();
  let cur = path;
  for (;;) {
    if (seen.has(cur)) return cur;
    seen.add(cur);
    const next = scan.byPath.get(cur)?.parentPaths[0];
    if (!next) return cur;
    cur = next;
  }
}

export function buildBreadcrumbChain(
  scan: ScanResult,
  projectRootPath: string,
  focusPath: string
): StudyNoteItem[] {
  const chain: StudyNoteItem[] = [];
  const seen = new Set<string>();
  let cur: string | undefined = focusPath;

  while (cur && !seen.has(cur)) {
    seen.add(cur);
    const item = scan.byPath.get(cur);
    if (!item) break;
    chain.unshift(item);
    if (cur === projectRootPath) break;
    cur = item.parentPaths[0];
  }

  const rootItem = scan.byPath.get(projectRootPath);
  if (rootItem && chain[0]?.path !== projectRootPath) {
    chain.unshift(rootItem);
  }
  return chain;
}

export function collectDescendants(path: string, scan: ScanResult): Set<string> {
  const result = new Set<string>();
  const stack: string[] = [path];
  while (stack.length > 0) {
    const cur = stack.pop();
    if (cur === undefined) break;
    for (const kid of scan.childrenOf.get(cur) ?? []) {
      if (kid === path || result.has(kid)) continue;
      result.add(kid);
      stack.push(kid);
    }
  }
  return result;
}

function matchesFilter(item: StudyNoteItem, filter: TreeFilterOptions): boolean {
  if (
    filter.typeFilter &&
    item.noteType.toLowerCase() !== filter.typeFilter.toLowerCase()
  ) {
    return false;
  }

  const q = filter.query.trim().toLowerCase();
  if (!q) return true;

  const tokens = q.split(/\s+/).filter(Boolean);
  const haystack = [
    item.name,
    item.noteType,
    item.discipline,
    ...item.tags.map((t) => `#${t}`),
  ]
    .join(" ")
    .toLowerCase();

  return tokens.every((tok) => haystack.includes(tok));
}

export function buildNestedFilteredTree(
  branchRoot: StudyNoteItem,
  scan: ScanResult,
  expanded: Set<string> | null,
  filter: TreeFilterOptions
): TreeNode[] {
  if (filter.mode === "orphans") {
    return scan.orphans
      .filter((it) => matchesFilter(it, { ...filter, mode: "all" }))
      .map((item) => ({
        item,
        depth: 0,
        hasChildren: false,
        isExpanded: false,
        directChildrenCount: 0,
        descendantCount: 0,
        isDirectMatch: true,
        children: [],
      }));
  }

  const isFiltering =
    filter.query.trim().length > 0 || filter.typeFilter.length > 0;

  const directMatches = new Set<string>();
  const visibleBranchPaths = new Set<string>();

  if (isFiltering) {
    const checkSubtree = (path: string, trail: Set<string>): boolean => {
      let anyChildMatched = false;
      for (const kidPath of scan.childrenOf.get(path) ?? []) {
        if (trail.has(kidPath)) continue;
        const kid = scan.byPath.get(kidPath);
        if (!kid) continue;
        trail.add(kidPath);
        const childHas = checkSubtree(kidPath, trail);
        trail.delete(kidPath);
        const selfMatch = matchesFilter(kid, filter);
        if (selfMatch) directMatches.add(kidPath);
        if (selfMatch || childHas) {
          visibleBranchPaths.add(kidPath);
          anyChildMatched = true;
        }
      }
      return anyChildMatched;
    };
    checkSubtree(branchRoot.path, new Set([branchRoot.path]));
  }

  const buildLevel = (
    parentPath: string,
    depth: number,
    trail: Set<string>
  ): TreeNode[] => {
    const kids = (scan.childrenOf.get(parentPath) ?? [])
      .map((p) => scan.byPath.get(p))
      .filter((x): x is StudyNoteItem => x !== undefined)
      .sort(byName);

    const levelNodes: TreeNode[] = [];

    for (const kid of kids) {
      if (trail.has(kid.path)) continue;
      if (isFiltering && !visibleBranchPaths.has(kid.path)) continue;

      const allKidChildren = scan.childrenOf.get(kid.path) ?? [];
      const hasChildren = isFiltering
        ? allKidChildren.some((k) => visibleBranchPaths.has(k))
        : allKidChildren.length > 0;

      const descendants = collectDescendants(kid.path, scan);
      const isExpanded =
        hasChildren &&
        (isFiltering || expanded === null || expanded.has(kid.path));

      let childrenNodes: TreeNode[] = [];
      if (isExpanded) {
        trail.add(kid.path);
        childrenNodes = buildLevel(kid.path, depth + 1, trail);
        trail.delete(kid.path);
      }

      levelNodes.push({
        item: kid,
        depth,
        hasChildren,
        isExpanded,
        directChildrenCount: allKidChildren.length,
        descendantCount: descendants.size,
        isDirectMatch: isFiltering ? directMatches.has(kid.path) : false,
        children: childrenNodes,
      });
    }

    return levelNodes;
  };

  return buildLevel(branchRoot.path, 0, new Set([branchRoot.path]));
}

export function flattenVisibleTree(nodes: TreeNode[]): TreeNode[] {
  const flat: TreeNode[] = [];
  const walk = (list: TreeNode[]) => {
    for (const n of list) {
      flat.push(n);
      if (n.isExpanded && n.children.length > 0) {
        walk(n.children);
      }
    }
  };
  walk(nodes);
  return flat;
}

function pickStableHashColor(str: string): string {
  let h = 2166136261;
  for (let i = 0; i < str.length; i++) {
    h ^= str.charCodeAt(i);
    h = Math.imul(h, 16777619);
  }

  return HASH_PALETTE[idx] ?? "var(--color-blue, #599ed6)";
}

const targetVersion = process.argv[2] || process.env.npm_package_version;
if (!targetVersion || !/^\d+\.\d+\.\d+$/.test(targetVersion)) {
  console.error("Использование: npm run bump <версия>");
  process.exit(1);
}

const manifest = JSON.parse(readFileSync("manifest.json", "utf8"));
const { minAppVersion } = manifest;
manifest.version = targetVersion;
writeFileSync("manifest.json", JSON.stringify(manifest, null, "\t") + "\n");

const pkg = JSON.parse(readFileSync("package.json", "utf8"));
pkg.version = targetVersion;
writeFileSync("package.json", JSON.stringify(pkg, null, "\t") + "\n");

let versions = {};
if (existsSync("versions.json")) {
  try { versions = JSON.parse(readFileSync("versions.json", "utf8")); } catch { versions = {}; }
}
versions[targetVersion] = minAppVersion;
writeFileSync("versions.json", JSON.stringify(versions, null, "\t") + "\n");
console.log(`Версия успешно обновлена до ${targetVersion}`);
