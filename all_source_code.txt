# Obsidian community plugin

## Project overview

- Target: Obsidian Community Plugin (TypeScript → bundled JavaScript).
- Entry point: `src/main.ts` compiled to `main.js` and loaded by Obsidian.
- Required release artifacts: `main.js`, `manifest.json`, and optional `styles.css`.

## Environment & tooling

- Node.js: use current LTS (Node 18+ recommended).
- **Package manager: npm** (required for this sample - `package.json` defines npm scripts and dependencies).
- **Bundler: esbuild** (required for this sample - `esbuild.config.mjs` and build scripts depend on it). Alternative bundlers like Rollup or webpack are acceptable for other projects if they bundle all external dependencies into `main.js`.
- Types: `obsidian` type definitions.

**Note**: This sample project has specific technical dependencies on npm and esbuild. If you're creating a plugin from scratch, you can choose different tools, but you'll need to replace the build configuration accordingly.

### Install

```bash
npm install
```

### Dev (watch)

```bash
npm run dev
```

### Production build

```bash
npm run build
```

## Linting

- ESLint is preconfigured with `eslint-plugin-obsidianmd` for Obsidian-specific rules.
- Run `npm run lint` to lint the project.
- A GitHub Action automatically lints every commit on all branches.

## File & folder conventions

- **Organize code into multiple files**: Split functionality across separate modules rather than putting everything in `main.ts`.
- Source lives in `src/`. Keep `main.ts` small and focused on plugin lifecycle (loading, unloading, registering commands).
- **Example file structure**:
    ```
    src/
      main.ts           # Plugin entry point, lifecycle management
      settings.ts       # Settings interface and defaults
      commands/         # Command implementations
        command1.ts
        command2.ts
      ui/              # UI components, modals, views
        modal.ts
        view.ts
      utils/           # Utility functions, helpers
        helpers.ts
        constants.ts
      types.ts         # TypeScript interfaces and types
    ```
- **Do not commit build artifacts**: Never commit `node_modules/`, `main.js`, or other generated files to version control.
- Keep the plugin small. Avoid large dependencies. Prefer browser-compatible packages.
- Generated output should be placed at the plugin root or `dist/` depending on your build setup. Release artifacts must end up at the top level of the plugin folder in the vault (`main.js`, `manifest.json`, `styles.css`).

## Manifest rules (`manifest.json`)

- Must include (non-exhaustive):
    - `id` (plugin ID; for local dev it should match the folder name)
    - `name`
    - `version` (Semantic Versioning `x.y.z`)
    - `minAppVersion`
    - `description`
    - `isDesktopOnly` (boolean)
    - Optional: `author`, `authorUrl`, `fundingUrl` (string or map)
- Never change `id` after release. Treat it as stable API.
- Keep `minAppVersion` accurate when using newer APIs.
- Canonical requirements are coded here: https://github.com/obsidianmd/obsidian-releases/blob/master/.github/workflows/validate-plugin-entry.yml

## Testing

- Manual install for testing: copy `main.js`, `manifest.json`, `styles.css` (if any) to:
    ```
    <Vault>/.obsidian/plugins/<plugin-id>/
    ```
- Reload Obsidian and enable the plugin in **Settings → Community plugins**.

## Commands & settings

- Any user-facing commands should be added via `this.addCommand(...)`.
- If the plugin has configuration, provide a settings tab and sensible defaults.
- Persist settings using `this.loadData()` / `this.saveData()`.
- Use stable command IDs; avoid renaming once released.

## Versioning & releases

- Bump `version` in `manifest.json` (SemVer) and update `versions.json` to map plugin version → minimum app version.
- Create a GitHub release whose tag exactly matches `manifest.json`'s `version`. Do not use a leading `v`.
- Attach `manifest.json`, `main.js`, and `styles.css` (if present) to the release as individual assets.
- After the initial release, follow the process to add/update your plugin in the community catalog as required.

## Security, privacy, and compliance

Follow Obsidian's **Developer Policies** and **Plugin Guidelines**. In particular:

- Default to local/offline operation. Only make network requests when essential to the feature.
- No hidden telemetry. If you collect optional analytics or call third-party services, require explicit opt-in and document clearly in `README.md` and in settings.
- Never execute remote code, fetch and eval scripts, or auto-update plugin code outside of normal releases.
- Minimize scope: read/write only what's necessary inside the vault. Do not access files outside the vault.
- Clearly disclose any external services used, data sent, and risks.
- Respect user privacy. Do not collect vault contents, filenames, or personal information unless absolutely necessary and explicitly consented.
- Avoid deceptive patterns, ads, or spammy notifications.
- Register and clean up all DOM, app, and interval listeners using the provided `register*` helpers so the plugin unloads safely.

## UX & copy guidelines (for UI text, commands, settings)

- Prefer sentence case for headings, buttons, and titles.
- Use clear, action-oriented imperatives in step-by-step copy.
- Use **bold** to indicate literal UI labels. Prefer "select" for interactions.
- Use arrow notation for navigation: **Settings → Community plugins**.
- Keep in-app strings short, consistent, and free of jargon.

## Performance

- Keep startup light. Defer heavy work until needed.
- Avoid long-running tasks during `onload`; use lazy initialization.
- Batch disk access and avoid excessive vault scans.
- Debounce/throttle expensive operations in response to file system events.

## Coding conventions

- TypeScript with `"strict": true` preferred.
- **Keep `main.ts` minimal**: Focus only on plugin lifecycle (onload, onunload, addCommand calls). Delegate all feature logic to separate modules.
- **Split large files**: If any file exceeds ~200-300 lines, consider breaking it into smaller, focused modules.
- **Use clear module boundaries**: Each file should have a single, well-defined responsibility.
- Bundle everything into `main.js` (no unbundled runtime deps).
- Avoid Node/Electron APIs if you want mobile compatibility; set `isDesktopOnly` accordingly.
- Prefer `async/await` over promise chains; handle errors gracefully.

## Mobile

- Where feasible, test on iOS and Android.
- Don't assume desktop-only behavior unless `isDesktopOnly` is `true`.
- Avoid large in-memory structures; be mindful of memory and storage constraints.

## Agent do/don't

**Do**

- Add commands with stable IDs (don't rename once released).
- Provide defaults and validation in settings.
- Write idempotent code paths so reload/unload doesn't leak listeners or intervals.
- Use `this.register*` helpers for everything that needs cleanup.

**Don't**

- Introduce network calls without an obvious user-facing reason and documentation.
- Ship features that require cloud services without clear disclosure and explicit opt-in.
- Store or transmit vault contents unless essential and consented.

## Common tasks

### Organize code across multiple files

**main.ts** (minimal, lifecycle only):

```ts
import { Plugin } from 'obsidian';
import { MySettings, DEFAULT_SETTINGS } from './settings';
import { registerCommands } from './commands';

export default class MyPlugin extends Plugin {
	settings!: MySettings;

	async onload() {
		this.settings = Object.assign(
			{},
			DEFAULT_SETTINGS,
			(await this.loadData()) as Partial<MySettings>,
		);
		registerCommands(this);
	}
}
```

**settings.ts**:

```ts
export interface MySettings {
	enabled: boolean;
	apiKey: string;
}

export const DEFAULT_SETTINGS: MySettings = {
	enabled: true,
	apiKey: '',
};
```

**commands/index.ts**:

```ts
import { Plugin } from 'obsidian';
import { doSomething } from './my-command';

export function registerCommands(plugin: Plugin) {
	plugin.addCommand({
		id: 'do-something',
		name: 'Do something',
		callback: () => doSomething(plugin),
	});
}
```

### Add a command

```ts
this.addCommand({
	id: 'your-command-id',
	name: 'Do the thing',
	callback: () => this.doTheThing(),
});
```

### Persist settings

```ts
interface MySettings { enabled: boolean }
const DEFAULT_SETTINGS: MySettings = { enabled: true };

async onload() {
  this.settings = Object.assign({}, DEFAULT_SETTINGS, await this.loadData() as Partial<MySettings>);
  await this.saveData(this.settings);
}
```

### Register listeners safely

```ts
this.registerEvent(
	this.app.workspace.on('file-open', (f) => {
		/* ... */
	}),
);
this.registerDomEvent(activeWindow, 'resize', () => {
	/* ... */
});
this.registerInterval(
	window.setInterval(() => {
		/* ... */
	}, 1000),
);
```

## Troubleshooting

- Plugin doesn't load after build: ensure `main.js` and `manifest.json` are at the top level of the plugin folder under `<Vault>/.obsidian/plugins/<plugin-id>/`.
- Build issues: if `main.js` is missing, run `npm run build` or `npm run dev` to compile your TypeScript source code.
- Commands not appearing: verify `addCommand` runs after `onload` and IDs are unique.
- Settings not persisting: ensure `loadData`/`saveData` are awaited and you re-render the UI after changes.
- Mobile-only issues: confirm you're not using desktop-only APIs; check `isDesktopOnly` and adjust.

# Obsidian Sample Plugin

This is a sample plugin for Obsidian (https://obsidian.md).

This project uses TypeScript to provide type checking and documentation.
The repo depends on the latest plugin API (obsidian.d.ts) in TypeScript Definition format, which contains TSDoc comments describing what it does.

This sample plugin demonstrates some of the basic functionality the plugin API can do.

- Adds a ribbon icon, which shows a Notice when clicked.
- Adds a command "Open modal (simple)" which opens a Modal.
- Adds a plugin setting tab to the settings page.
- Registers a global click event and outputs a Notice on click.
- Registers a global interval which logs 'setInterval' to the console.

## First time developing plugins?

Quick starting guide for new plugin devs:

- Check if [someone already developed a plugin for what you want](https://obsidian.md/plugins)! There might be an existing plugin similar enough that you can partner up with.
- Make a copy of this repo as a template with the "Use this template" button (login to GitHub if you don't see it).
- Clone your repo to a local development folder. For convenience, you can place this folder in your `.obsidian/plugins/your-plugin-name` folder.
- Install NodeJS, then run `npm i` in the command line under your repo folder.
- Run `npm run dev` to compile your plugin from `src/main.ts` to `main.js`.
- Make changes to `src/main.ts` (or create new `.ts` files). Those changes should be automatically compiled into `main.js`.
- Reload Obsidian to load the new version of your plugin.
- Enable plugin in settings window.
- For updates to the Obsidian API run `npm update` in the command line under your repo folder.

## Releasing new releases

- Update your `manifest.json` with your new version number, such as `1.0.1`, and the minimum Obsidian version required for your latest release.
- Update your `versions.json` file with `"new-plugin-version": "minimum-obsidian-version"` so older versions of Obsidian can download an older version of your plugin that's compatible.
- Create new GitHub release using your new version number as the "Tag version". Use the exact version number, don't include a prefix `v`. See here for an example: https://github.com/obsidianmd/obsidian-sample-plugin/releases
- Upload the files `manifest.json`, `main.js`, `styles.css` as binary attachments. Note: The manifest.json file must be in two places, first the root path of your repository and also in the release.
- Publish the release.

> You can simplify the version bump process by running `npm version patch`, `npm version minor` or `npm version major` after updating `minAppVersion` manually in `manifest.json`.
> The command will bump version in `manifest.json` and `package.json`, and add the entry for the new version to `versions.json`

## Adding your plugin to the community plugin list

- Check the [plugin guidelines](https://docs.obsidian.md/Plugins/Releasing/Plugin+guidelines).
- Publish an initial version.
- Make sure you have a `README.md` file in the root of your repo.
- Make a pull request at https://github.com/obsidianmd/obsidian-releases to add your plugin.

## How to use

- Clone this repo.
- Make sure your NodeJS is at least v18 (`node --version`).
- `npm i` to install dependencies.
- `npm run dev` to start compilation in watch mode.

## Manually installing the plugin

- Copy over `main.js`, `styles.css`, `manifest.json` to your vault `VaultFolder/.obsidian/plugins/your-plugin-id/`.

## Improve code quality with eslint

- [ESLint](https://eslint.org/) is a tool that analyzes your code to quickly find problems. You can run ESLint against your plugin to find common bugs and ways to improve your code.
- This project already has eslint preconfigured, you can invoke a check by running`npm run lint`
- Together with a custom eslint [plugin](https://github.com/obsidianmd/eslint-plugin) for Obsidan specific code guidelines.
- A GitHub action is preconfigured to automatically lint every commit on all branches.


    if ((lines[i] ?? "").trim().length > 0) {
      firstNonEmpty = i;
      break;
    }
  }
  if (firstNonEmpty === -1) return "";

  const firstLine = (lines[firstNonEmpty] ?? "").trim();
  if (firstLine.startsWith("#")) {
    const cleanHeading = firstLine.replace(/^#+\s*/, "").trim().toLowerCase();
    const cleanTitle = noteTitle.trim().toLowerCase();
    if (cleanHeading === cleanTitle || firstLine.startsWith("# ")) {
      lines.splice(firstNonEmpty, 1);
      return lines.join("\n").trim();
    }
  }
  return body.trim();
}

function adjustInternalHeadings(body: string, baseHashesCount: number): string {
  const shift = Math.max(0, baseHashesCount - 1);
  if (shift <= 0) return body;

  let inCodeBlock = false;
  return body
    .split(/\r?\n/)
    .map((line) => {
      if (line.trimStart().startsWith("```")) {
        inCodeBlock = !inCodeBlock;
        return line;
      }
      if (inCodeBlock) return line;
      const m = line.match(/^(#{1,6})(\s+.*)$/);
      if (!m || !m[1] || !m[2]) return line;
      const nextCount = Math.min(6, m[1].length + shift);
      return "#".repeat(nextCount) + m[2];
    })
    .join("\n");
}

function extractWikiLinksFromText(text: string): string[] {
  const results: string[] = [];
  const regex = /\[\[([^\]|#]+)(?:#[^\]|]+)?(?:\|[^\]]+)?\]\]/g;
  let m: RegExpExecArray | null;
  while ((m = regex.exec(text)) !== null) {
    const rawTarget = (m[1] ?? "").trim();
    if (rawTarget) results.push(rawTarget);
  }
  return results;
}

function formatBibliographyEntry(sourceNote: StudyNoteItem, body: string): string {
  const firstParagraph = body
    .split(/\r?\n/)
    .map((l) => l.trim())
    .find((l) => l.length > 0 && !l.startsWith("#"));

  if (firstParagraph) {
    const clean = firstParagraph.replace(/^[-*+]\s+/, "").trim();
    if (clean.length >= 10) {
      return clean;
    }
  }
  if (sourceNote.sourceProp) {
    return `${sourceNote.name} — ${sourceNote.sourceProp}`;
  }
  return sourceNote.name;
}

export function buildAuditAndCompileProject(
  rootWork: StudyNoteItem,
  rootBodyText: string,
  nodes: HierarchyNode[],
  config: ProjectCompileConfig,
  outputFolder: string
): CompilationResult {
  const includedNodes = nodes.filter((n) => n.included);

  // Собираем весь текст включённых разделов (кроме самих карточек источников) для проверки цитирований
  const narrativeChunks: string[] = [];
  if (config.includeRootBody && rootBodyText) {
    narrativeChunks.push(rootBodyText);
  }
  for (const n of includedNodes) {
    if (n.item.noteType !== "Источник") {
      narrativeChunks.push(n.bodyText);
    }
  }
  const combinedNarrative = narrativeChunks.join("\n\n");
  const allLinkedTargetsLower = new Set(
    extractWikiLinksFromText(combinedNarrative).map((s) =>
      s.replace(/\.md$/i, "").toLowerCase()
    )
  );

  const isNoteReferencedInNarrative = (item: StudyNoteItem): boolean => {
    const nameLower = item.name.toLowerCase();
    const pathLower = item.path.replace(/\.md$/i, "").toLowerCase();
    return (
      allLinkedTargetsLower.has(nameLower) ||
      allLinkedTargetsLower.has(pathLower)
    );
  };

  const sourcesTotal = includedNodes
    .filter((n) => n.item.noteType === "Источник")
    .map((n) => n.item);
  const sourcesCited = sourcesTotal.filter(isNoteReferencedInNarrative);
  const sourcesUncited = sourcesTotal.filter(
    (s) => !isNoteReferencedInNarrative(s)
  );

  const visualsTotal = includedNodes
    .filter((n) =>
      ["Рисунок", "Схема", "Таблица"].includes(n.item.noteType)
    )
    .map((n) => n.item);
  const visualsReferenced = visualsTotal.filter(isNoteReferencedInNarrative);
  const visualsUnreferenced = visualsTotal.filter(
    (v) => !isNoteReferencedInNarrative(v)
  );

  const emptySectionNotes = includedNodes
    .filter(
      (n) =>
        n.item.noteType !== "Источник" &&
        n.item.noteType !== "Рисунок" &&
        n.item.noteType !== "Схема" &&
        n.wordCount < 5
    )
    .map((n) => n.item);

  // Сквозная нумерация источников в порядке первого упоминания (затем остальные привязанные источники)
  const sourceNumberMap = new Map<string, number>();
  const orderedSourcesForBib: HierarchyNode[] = [];
  const sourceNodes = includedNodes.filter(
    (n) => n.item.noteType === "Источник"
  );
  const sourceByLowerName = new Map<string, HierarchyNode>();
  for (const sn of sourceNodes) {
    sourceByLowerName.set(sn.item.name.toLowerCase(), sn);
    sourceByLowerName.set(sn.item.path.replace(/\.md$/i, "").toLowerCase(), sn);
  }

  for (const linkTarget of extractWikiLinksFromText(combinedNarrative)) {
    const key = linkTarget.replace(/\.md$/i, "").toLowerCase();
    const matchedSource = sourceByLowerName.get(key);
    if (matchedSource && !sourceNumberMap.has(matchedSource.item.path)) {
      const nextNum = orderedSourcesForBib.length + 1;
      sourceNumberMap.set(matchedSource.item.path, nextNum);
      orderedSourcesForBib.push(matchedSource);
    }
  }
  for (const sn of sourceNodes) {
    if (!sourceNumberMap.has(sn.item.path)) {
      const nextNum = orderedSourcesForBib.length + 1;
      sourceNumberMap.set(sn.item.path, nextNum);
      orderedSourcesForBib.push(sn);
    }
  }

  const replaceCitationsInText = (text: string): string => {
    if (!config.replaceSourceLinksWithNumbers || sourceNumberMap.size === 0) {
      return text;
    }
    return text.replace(
      /(?<!!)\[\[([^\]|#]+)(?:#[^\]|]+)?(?:\|[^\]]+)?\]\]/g,
      (fullMatch, rawTarget: string) => {
        const key = String(rawTarget ?? "")
          .trim()
          .replace(/\.md$/i, "")
          .toLowerCase();
        const found = sourceByLowerName.get(key);
        if (!found) return fullMatch;
        const num = sourceNumberMap.get(found.item.path);
        return num !== undefined ? `[${num}]` : fullMatch;
      }
    );
  };

  // Сборка итогового Markdown-документа
  const outLines: string[] = [];
  const todayISO = new Date().toISOString().slice(0, 10);

  outLines.push("---");
  outLines.push(`направление: "Учёба"`);
  outLines.push(`тип: "Сборка"`);
  outLines.push(`проект: "[[${rootWork.name}]]"`);
  outLines.push(`дата_сборки: "${todayISO}"`);
  if (rootWork.discipline) {
    outLines.push(`дисциплина: ${JSON.stringify(rootWork.discipline)}`);
  }
  outLines.push("---");
  outLines.push("");
  outLines.push(`# ${rootWork.name}`);
  outLines.push("");

  if (config.includeRootBody && rootBodyText) {
    const cleanedRoot = config.stripLeadingH1
      ? removeLeadingHeadingIfMatches(rootBodyText, rootWork.name)
      : rootBodyText;
    if (cleanedRoot) {
      outLines.push(replaceCitationsInText(cleanedRoot));
      outLines.push("");
    }
  }

  let figureCounter = 0;
  let tableCounter = 0;

  // 1. Глоссарий терминов (если включён сбор терминов в отдельный раздел)
  const termNodes = includedNodes.filter((n) => n.item.noteType === "Термин");
  if (config.groupTermsIntoGlossary && termNodes.length > 0) {
    outLines.push("## Термины и определения");
    outLines.push("");
    for (const tn of termNodes) {
      const cleanTermBody = removeLeadingHeadingIfMatches(
        tn.bodyText,
        tn.item.name
      )
        .replace(/\r?\n+/g, " ")
        .trim();
      outLines.push(
        `- **${tn.item.name}** — ${replaceCitationsInText(cleanTermBody || "определение не заполнено")}`
      );
    }
    outLines.push("");
  }

  // 2. Основные разделы работы по дереву иерархии
  for (const node of includedNodes) {
    const t = node.item.noteType;
    if (config.buildBibliography && t === "Источник") continue;
    if (config.groupTermsIntoGlossary && t === "Термин") continue;

    const headingLevel = Math.min(6, node.depth + 2);
    const hashes = "#".repeat(headingLevel);
    const numPrefix =
      config.numberSections && node.sectionNumber !== "—"
        ? `${node.sectionNumber}. `
        : "";

    let sectionTitle = `${hashes} ${numPrefix}${node.item.name}`;
    if (config.autoNumberFiguresAndTables) {
      if (t === "Рисунок" || t === "Схема") {
        figureCounter++;
        sectionTitle = `${hashes} Рисунок ${figureCounter} — ${node.item.name}`;
      } else if (t === "Таблица") {
        tableCounter++;
        sectionTitle = `${hashes} Таблица ${tableCounter} — ${node.item.name}`;
      }
    }

    outLines.push(sectionTitle);
    outLines.push("");

    let body = config.stripLeadingH1
      ? removeLeadingHeadingIfMatches(node.bodyText, node.item.name)
      : node.bodyText;
    body = adjustInternalHeadings(body, headingLevel);
    body = replaceCitationsInText(body);

    if (body) {
      outLines.push(body);
      outLines.push("");
    }
  }

  // 3. Список использованных источников
  if (config.buildBibliography && orderedSourcesForBib.length > 0) {
    outLines.push("## Список использованных источников");
    outLines.push("");
    orderedSourcesForBib.forEach((sn, idx) => {
      const num = idx + 1;
      const entryText = formatBibliographyEntry(sn.item, sn.bodyText);
      outLines.push(`${num}. ${entryText}`);
    });
    outLines.push("");
  }

  const finalMarkdown = outLines.join("\n").trim() + "\n";
  const finalStats = countWordsAndFormulas(finalMarkdown);
  const markdownTablesCount =
    visualsTotal.filter((v) => v.noteType === "Таблица").length +
    (finalMarkdown.match(/\n\|[-:\s|]+\|\r?\n/g) ?? []).length;
  const embeddedImagesCount =
    visualsTotal.filter(
      (v) => v.noteType === "Рисунок" || v.noteType === "Схема"
    ).length +
    (finalMarkdown.match(/!\[\[[^\]]+\.(?:png|jpg|jpeg|webp|svg|gif)/gi) ?? [])
      .length;

  const audit: ProjectAuditReport = {
    totalNodes: nodes.length,
    includedNodes: includedNodes.length,
    totalWords: finalStats.words,
    totalCharsWithSpaces: finalStats.chars,
    authorSheets: (finalStats.chars / 40_000).toFixed(2).replace(".", ","),
    approxPages: Math.max(1, Math.ceil(finalStats.chars / 1800)),
    totalFormulas: finalStats.formulas,
    totalTables: markdownTablesCount,
    totalFigures: embeddedImagesCount,
    sourcesTotal,
    sourcesCited,
    sourcesUncited,
    visualsTotal,
    visualsReferenced,
    visualsUnreferenced,
    emptySectionNotes,
  };

  const safeFolder = (outputFolder || "Знания/Сборки").replace(/\/+$/, "");
  const safeName = rootWork.name.replace(/[\\/:*?"<>|]/g, "").trim();
  const outputFilePath = normalizePath(
    `${safeFolder}/Сборка — ${safeName}.md`
  );

  return {
    markdown: finalMarkdown,
    outputFilePath,
    audit,
  };
}

export async function ensureVaultFolderExists(app: App, folderPath: string) {
  let current = "";
  for (const part of normalizePath(folderPath).split("/").filter(Boolean)) {
    current = current ? `${current}/${part}` : part;
    if (!app.vault.getAbstractFileByPath(current)) {
      try {
        await app.vault.createFolder(current);
      } catch {
        // Игнорируем, если папка уже создана параллельно
      }
    }
  }
}

export async function writeCompiledFileToVault(
  app: App,
  outputFilePath: string,
  markdown: string
): Promise<TFile> {
  const folder = outputFilePath.includes("/")
    ? outputFilePath.slice(0, outputFilePath.lastIndexOf("/"))
    : "";
  if (folder) {
    await ensureVaultFolderExists(app, folder);
  }

  const existing = app.vault.getAbstractFileByPath(outputFilePath);
  if (existing instanceof TFile) {
    await app.vault.modify(existing, markdown);
    return existing;
  }
  return await app.vault.create(outputFilePath, markdown);
}

function stripOuterWikiBrackets(str: string): string {
  let s = String(str || "").trim();
  if (s.startsWith("[[")) s = s.slice(2);
  if (s.endsWith("]]")) s = s.slice(0, -2);
  return s;
}

function flattenFrontmatterValue(val: unknown): string[] {
  if (val === null || val === undefined) return [];
  if (Array.isArray(val)) {
    const res: string[] = [];
    for (const item of val) {
      res.push(...flattenFrontmatterValue(item));
    }
    return res;
  }
  if (typeof val === "object" && (val as { path?: unknown }).path) {
    return [String((val as { path: unknown }).path).trim()];
  }
  const s = String(val).trim();
  return s ? [s] : [];
}

export function resolveParentPaths(
  app: App,
  file: TFile,
  rawParentProp: unknown
): string[] {
  const rawList = flattenFrontmatterValue(rawParentProp);
  const resolved: string[] = [];

  for (const raw of rawList) {
    const clean = stripOuterWikiBrackets(raw)
      .split("|")[0]
      ?.split("#")[0]
      ?.trim();
    if (!clean) continue;

    const direct = app.vault.getAbstractFileByPath(clean);
    if (direct instanceof TFile) {
      if (!resolved.includes(direct.path)) resolved.push(direct.path);
      continue;
    }

    const withMd = app.vault.getAbstractFileByPath(
      clean.endsWith(".md") ? clean : `${clean}.md`
    );
    if (withMd instanceof TFile) {
      if (!resolved.includes(withMd.path)) resolved.push(withMd.path);
      continue;
    }

    const dest = app.metadataCache.getFirstLinkpathDest(clean, file.path);
    if (dest instanceof TFile && !resolved.includes(dest.path)) {
      resolved.push(dest.path);
    }
  }

  return resolved;
}

export function stripYamlFrontmatter(rawContent: string): string {
  const text = String(rawContent ?? "");
  if (!text.startsWith("---")) return text.trim();
  const match = text.match(/^---\r?\n[\s\S]*?\r?\n---\r?\n?/);
  if (!match || !match[0]) return text.trim();
  return text.slice(match[0].length).trim();
}

export function countWordsAndFormulas(cleanBody: string): {
  words: number;
  chars: number;
  formulas: number;
} {
  const trimmed = cleanBody.trim();
  if (!trimmed) return { words: 0, chars: 0, formulas: 0 };

  const blockFormulas = (trimmed.match(/\$\$[\s\S]*?\$\$/g) ?? []).length;
  const withoutBlock = trimmed.replace(/\$\$[\s\S]*?\$\$/g, " ");
  const inlineFormulas = (withoutBlock.match(/\$[^\s$][^$\n]*?\$/g) ?? []).length;

  const plain = trimmed
    .replace(/!\[\[[^\]]+\]\]/g, " ")
    .replace(/\[\[([^\]|]+)\|([^\]]+)\]\]/g, "$2")
    .replace(/\[\[([^\]]+)\]\]/g, "$1")
    .replace(/[#*_`~>|]/g, " ")
    .replace(/\s+/g, " ")
    .trim();

  const words = plain ? plain.split(" ").filter(Boolean).length : 0;
  return {
    words,
    chars: plain.length,
    formulas: blockFormulas + inlineFormulas,
  };
}

export function scanStudyVault(
  app: App,
  settings: StudyCompilerSettings
): {
  works: StudyNoteItem[];
  byPath: Map<string, StudyNoteItem>;
  childrenOf: Map<string, string[]>;
} {
  const areaTarget = (settings.studyAreaName || "Учёба").trim();
  const decksPrefix =
    (settings.decksFolder || "Знания/Карточки").replace(/\/+$/, "") + "/";
  const outPrefix =
    (settings.outputFolder || "Знания/Сборки").replace(/\/+$/, "") + "/";
  const tplPrefix = settings.templatePrefix || "Учёба — ";

  const byPath = new Map<string, StudyNoteItem>();
  const childrenOf = new Map<string, string[]>();

  for (const file of app.vault.getMarkdownFiles()) {
    if (
      file.basename.startsWith(tplPrefix) ||
      file.path.startsWith("Шаблоны/") ||
      file.path.startsWith("Templates/") ||
      file.path.startsWith(decksPrefix) ||
      file.path.startsWith(outPrefix)
    ) {
      continue;
    }

    const fm = app.metadataCache.getFileCache(file)?.frontmatter;
    if (!fm) continue;

    const areaList = flattenFrontmatterValue(fm["направление"]);
    if (!areaList.includes(areaTarget)) continue;

    const isCardDeck =
      Boolean(fm["колода_карточек"]) ||
      String(fm["подтип"] ?? "").trim().toLowerCase() === "карточки";
    if (isCardDeck) continue;

    const noteType = String(fm["тип"] ?? "").trim();
    const status = String(fm["статус"] ?? "").trim();
    const discipline = String(fm["дисциплина"] ?? "").trim();
    const sourceProp = String(fm["источник"] ?? "").trim();
    const customIcon = String(fm["иконка"] ?? "").trim();
    const rawDeadline = fm["срок"] ? String(fm["срок"]).slice(0, 10) : null;
    const parentPaths = resolveParentPaths(app, file, fm["родитель"]);

    const isWork =
      Boolean(noteType) &&
      !MATERIAL_TYPES.includes(noteType) &&
      parentPaths.length === 0 &&
      (PRESET_WORK_TYPES.includes(noteType) || fm["статус"] !== undefined);

    const isActiveWork =
      isWork && !DONE_STATUSES.includes(status.toLowerCase());

    const item: StudyNoteItem = {
      file,
      path: file.path,
      name: file.basename,
      noteType: noteType || "Заметка",
      status,
      discipline,
      deadlineISO: rawDeadline,
      sourceProp,
      customIcon,
      parentPaths,
      isWork,
      isActiveWork,
    };

    byPath.set(file.path, item);

    for (const pPath of parentPaths) {
      const list = childrenOf.get(pPath) ?? [];
      if (!list.includes(file.path)) {
        list.push(file.path);
        childrenOf.set(pPath, list);
      }
    }
  }

  const works = [...byPath.values()]
    .filter((it) =>
      settings.showCompletedWorks ? it.isWork : it.isActiveWork
    )
    .sort((a, b) => {
      if (a.isActiveWork !== b.isActiveWork) return a.isActiveWork ? -1 : 1;
      const dA = a.deadlineISO ?? "9999-99-99";
      const dB = b.deadlineISO ?? "9999-99-99";
      return dA.localeCompare(dB) || a.name.localeCompare(b.name, "ru");
    });

  return { works, byPath, childrenOf };
}

export async function buildProjectHierarchy(
  app: App,
  rootWork: StudyNoteItem,
  byPath: Map<string, StudyNoteItem>,
  childrenOf: Map<string, string[]>,
  config: ProjectCompileConfig
): Promise<{
  rootBodyText: string;
  rootWords: number;
  nodes: HierarchyNode[];
}> {
  const cfg = { ...DEFAULT_COMPILE_CONFIG, ...config };
  const orderIndexMap = new Map<string, number>();
  cfg.orderedPaths.forEach((p, idx) => orderIndexMap.set(p, idx));
  const excludedSet = new Set(cfg.excludedPaths);

  const visited = new Set<string>([rootWork.path]);
  const rawNodes: Array<{
    item: StudyNoteItem;
    depth: number;
    parentPath: string;
  }> = [];

  const typePriority = (t: string): number => {
    if (t === "Конспект" || t === "Заметка") return 1;
    if (t === "Алгоритм" || t === "Расчёт") return 2;
    if (t === "Таблица" || t === "Рисунок" || t === "Схема") return 3;
    if (t === "Термин") return 4;
    if (t === "Источник") return 5;
    return 2;
  };

  const walk = (currentPath: string, depth: number) => {
    const kids = (childrenOf.get(currentPath) ?? [])
      .map((kPath) => byPath.get(kPath))
      .filter((k): k is StudyNoteItem => Boolean(k && !k.isWork));

    kids.sort((a, b) => {
      const idxA = orderIndexMap.get(a.path);
      const idxB = orderIndexMap.get(b.path);
      if (idxA !== undefined && idxB !== undefined) return idxA - idxB;
      if (idxA !== undefined) return -1;
      if (idxB !== undefined) return 1;
      const pDiff = typePriority(a.noteType) - typePriority(b.noteType);
      if (pDiff !== 0) return pDiff;
      return a.name.localeCompare(b.name, "ru");
    });

    for (const kid of kids) {
      if (visited.has(kid.path)) continue;
      visited.add(kid.path);
      rawNodes.push({ item: kid, depth, parentPath: currentPath });
      walk(kid.path, depth + 1);
    }
  };

  walk(rootWork.path, 0);

  let rootBodyText = "";
  try {
    const rawRoot = await app.vault.cachedRead(rootWork.file);
    rootBodyText = stripDataviewCodeblocks(stripYamlFrontmatter(rawRoot));
  } catch {
    rootBodyText = "";
  }
  const rootStats = countWordsAndFormulas(rootBodyText);

  const counters: number[] = [];
  const nodes: HierarchyNode[] = [];

  for (const rn of rawNodes) {
    let bodyText = "";
    try {
      const raw = await app.vault.cachedRead(rn.item.file);
      bodyText = stripDataviewCodeblocks(stripYamlFrontmatter(raw));
    } catch {
      bodyText = "";
    }

    const included = !excludedSet.has(rn.item.path);
    const isSpecialBottom =
      (cfg.buildBibliography && rn.item.noteType === "Источник") ||
      (cfg.groupTermsIntoGlossary && rn.item.noteType === "Термин");

    let sectionNumber = "—";
    if (included && !isSpecialBottom) {
      const d = rn.depth;
      while (counters.length <= d) counters.push(0);
      counters.splice(d + 1);
      counters[d] = (counters[d] ?? 0) + 1;
      sectionNumber = counters.join(".");
    }

    const st = countWordsAndFormulas(bodyText);
    nodes.push({
      item: rn.item,
      depth: rn.depth,
      parentPath: rn.parentPath,
      sectionNumber,
      included,
      wordCount: st.words,
      charCount: st.chars,
      formulaCount: st.formulas,
      bodyText,
    });
  }

  return {
    rootBodyText,
    rootWords: rootStats.words,
    nodes,
  };
}
